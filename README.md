# RoseLine — женский салон красоты в Ереване

Многостраничный сайт салона (RU / HY / EN), mobile-first.

Сайт: https://ayanamiraaaay.github.io/roseline/

- Онлайн-запись: заявка уходит в WhatsApp или Telegram салона. Номера задаются в `js/app.js` (объект `SALON`).
- Калькулятор цены с уровнем мастера и длиной волос, прайс, работы с фильтром, мастера, отзывы, FAQ, сертификаты, карта постоянной клиентки, блог.
- Значения в квадратных скобках (`[N]`, `[улица, дом]`, `[Имя мастера]`, рейтинг, отзывы) нужно заменить на настоящие.

Фото: [Unsplash](https://unsplash.com) (Unsplash License) — демо, заменить на фото салона.
